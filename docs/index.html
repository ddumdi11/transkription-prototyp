Was es kann

Ein schlankes Werkzeug für den täglichen Diktat-Workflow – von der Rohaufnahme bis zur sauberen Markdown-Datei.

🎙️

Viele Audioformate

MP3, WAV, M4A, FLAC, OGG, WebM – einzeln oder ganze Ordner als Batch.

☁️🔒

Cloud oder lokal

OpenAI-Transkription für beste Bequemlichkeit – oder lokal mit faster-whisper: kostenlos und ohne dass deine Aufnahmen den Rechner verlassen.

🔗

Audio zusammenfügen

Mehrere Aufnahme-Schnipsel einer Session werden intelligent sortiert und zu einer Datei verbunden.

✏️

Bessere Erkennung

Kontext-Prompt für Fachbegriffe und automatische Korrektur bekannter Erkennungsfehler.

✂️

Große Dateien

Aufnahmen über dem API-Limit werden automatisch geteilt, transkribiert und wieder zusammengesetzt.

🖥️

GUI & CLI

Klick-Oberfläche für gelegentliche Nutzung, Kommandozeile für Automatisierung.

Schnellstart

In wenigen Minuten einsatzbereit. Python 3.10+ und ffmpeg vorausgesetzt.

Repository holen & Abhängigkeiten installieren 
git clone https://github.com/ddumdi11/transkription-prototyp.git
cd transkription-prototyp
pip install -r requirements.txt
API-Key hinterlegen (nur für die Cloud-Variante)
.env anlegen mit OPENAI_API_KEY=dein-key.
Oberfläche starten 
python gui.py
Oder per Kommandozeile transkribieren 
python transcribe.py input --prompt "Fachbegriffe: Diktiergerät, Claude, KI"
Die fertigen Transkripte landen als .md-Dateien im Ordner output/.
